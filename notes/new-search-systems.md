ready search engine that can support both people and
agent search in the future, where people's search
pattern could evolve with the new chat interface like
google AI.

the newest technology. It has 20MM skus and need to
satisfy top QPS of 10k.

cases in the following order of priority:

1:From target apps and web: (key)

b. online customer natrual language search, potentially
multi-turn and complex problem solving

2: From chat bots: when people search and ask products on
chatGPT, perplexity, geimini, they can find target
products, and potentially put them on the top

3: SEO traffic: when people search on google or some
search engines, SO

4: Search from agentic
1. when target's internal agents or external agents
are searching against target catalog.

Design the system in the way that with the best user
experience as the goal. Don't worry about the cost of
